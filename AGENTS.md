## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues via the `gh` CLI. Credential choice for issues and the project board is in `docs/agents/issue-tracker.md`.

### Triage labels

Canonical roles map 1:1 to `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Ticket management

New issues start in Backlog with `needs-triage`. Triage asks the maintainer to validate the body and agree on an agent brief before a ticket is marked ready. See `docs/agents/triage.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
