# Site

Jonathan Ortega's personal site and digital garden.

## Language

**Page**:
A URL.
_Avoid_: screen, view, route

**Page document**:
A Sanity document rendered with the page wrapper.
_Avoid_: page type

**Post document**:
A Sanity document rendered with the post wrapper.
_Avoid_: blog post, article, garden entry

**Page wrapper**:
The shell for a page document.
_Avoid_: page layout, template

**Post wrapper**:
The shell for a post document. The wrapper is where a page document and a post document differ.
_Avoid_: article layout, garden layout

**Content**:
The ordered set of components inside a wrapper.
_Avoid_: copy, page data, hardcoded module
